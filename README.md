A modern, responsive, multi-page personal portfolio website designed and developed for **Ndyamuhaki Samuel**, a **Bachelor of Business Computing** scholar at **Bugema University**.

---

## 📌 Project Overview
This website satisfies all academic requirements for web design, responsive layouts, multimedia integration, and version control. It demonstrates the powerful intersection between **business processes** and **computing systems**, presenting Samuel's academic trajectory, technical competencies, self-motivation video statement, photo gallery, and interactive contact channels.

---

## 🗂️ Website Structure & Pages

| Page | Filename | Description & Core Features |
| :--- | :--- | :--- |
| **Home Page** | [`index.html`](index.html) | Sticky Bootstrap navbar, engaging hero banner with welcome heading & tagline, CTA buttons, interactive counters, and 3 teaser highlight cards (Program, Skills, Projects). |
| **About Me** | [`about.html`](about.html) | In-depth biography, academic timeline at Bugema University, coursework table (SQL, ERP, Systems Analysis), visual skill progress bars, and personal hobbies. |
| **Gallery & Video** | [`gallery.html`](gallery.html) | **Mandatory self-motivation video statement** (HTML5 `<video>` container with sample playback, captions, and collapsible speech transcript) + 6-card responsive photo gallery with category filter and modal lightbox. |
| **Contacts** | [`contact.html`](contact.html) | Professional university and direct contact info, interactive Bootstrap contact form with real-time validation and submission alerts, plus an embedded Google map of Bugema University. |

## 🎨 Design System & Aesthetics
- **Theme**: *Clean Professional Light* (Modern crisp corporate tech style).
- **Typography**: `Plus Jakarta Sans` for clean, professional headings & body readability, paired with `Space Grotesk` for brand accents.
- **Color Palette**:
  - Deep Navy Blue (`#1e3a8a`) & Electric Accent (`#2563eb`)
  - Tech Cyan (`#0284c7`) & Growth Emerald (`#059669`)
  - Crisp Slate Light Background (`#f8fafc`) with subtle borders (`#e2e8f0`)
- **Interactive Micro-Animations**: Card hover lifts, floating badges, animated counters, smooth scroll navigation, and responsive lightbox preview.

## 🚀 Live Deployment via GitHub Pages

Follow these simple steps to deploy this project live online:

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and click **New Repository**.
   - Name it: `samuel-portfolio-website` (or your preferred name).
   - Set visibility to **Public**.
2. **Push Your Files**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Complete 4-page Business Computing portfolio for Ndyamuhaki Samuel"
   git branch -M main
   git remote add origin https://github.com/<your-github-username>/samuel-portfolio-website.git
   git push -u origin main
   ```
3. **Enable GitHub Pages**:
   - In your repository, click **Settings** &rarr; **Pages** (under Code and automation).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/(root)`, then click **Save**.
   - In 1–2 minutes, your live website URL will be ready at:  
     `https://<your-github-username>.github.io/samuel-portfolio-website/`
